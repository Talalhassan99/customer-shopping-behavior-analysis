# Dataset

This project uses a customer shopping behavior dataset containing 3,900 purchase transactions and 18 features.

The dataset includes customer demographics, purchase details, product information, shopping behavior, subscription status, shipping information, and review ratings.

## Dataset Information

- Rows: 3,900
- Columns: 18
- Data type: Customer purchase transactions

## Data Availability

The raw CSV dataset is not included in this repository.

The dataset was used for educational and portfolio analysis purposes.

## Data Preparation

The dataset was cleaned and prepared using Python and Pandas before being loaded into PostgreSQL for SQL-based analysis.
